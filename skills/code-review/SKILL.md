# Code Review Skill

按以下顺序审查：

1. **正确性**：边界条件、空值、并发、错误路径、数据一致性。
2. **安全性**：注入、路径穿越、SSRF、权限绕过、密钥泄漏。
3. **可测试性**：是否能稳定复现；缺少哪些关键用例。
4. **可维护性**：重复、隐藏耦合、过度抽象。
5. **验证**：实际运行了哪些命令，未验证什么。

输出格式：

- 先给结论（可合并 / 需修改 / 阻塞）
- 按 `P0/P1/P2` 列出问题，附文件与行号
- 最后列出验证结果和剩余风险
